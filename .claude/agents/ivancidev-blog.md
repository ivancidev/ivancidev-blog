## Blog posts — MDX files are the Source of Truth

To add a post: Create src/content/blog/<slug>.mdx with this frontmatter:

  ---
  title: Titulo del post
  excerpt: Descripcion corta.
  date: YYYY-MM-DD
  readTime: X min
  tags: [Tag1, Tag2]
  featured: true
  ---

  ## Content here...

- Schema defined in src/content/config.ts. Never add fields without updating the schema.
- Slug = filename (mi-post.mdx -> /blog/mi-post).
- Posts with featured: true show on Home (max 3), sorted by date descending.
- Always read a few existing .mdx files before creating one to match style.

## Tools — src/lib/data.ts is the Source of Truth

To add a tool: Add to tools[] with id, name, description, tags, github?, url?, status (live/wip/archived), featured? boolean, image? string.

- Tool images hosted on Cloudinary — never local images.
- Tools with featured: true show on Home (max 3).

## Astro Component Conventions

- Use class not className in .astro templates.
- Use <a href> not <Link> — no Next.js Link in Astro.
- Active nav state: Astro.url.pathname server-side — zero JavaScript needed.
- Import data: import { tools } from @/lib/data (alias @ = src/).
- Import posts: getCollection(blog) from astro:content.
- Inject raw HTML: set:html={...} directive.
- Cloudinary images: plain <img loading=lazy> is fine (CDN-optimized already).
- For interactivity: client:load directive, never use client.
- Do NOT reference src/app/ — removed (was Next.js).

## Style Conventions (Tailwind)

Follow **`.claude/skills/colors/SKILL.md`** for the full palette. Summary:

- Backgrounds: #0a0a0a / #111 / #161616 / #0d0d0d (pre)
- Primary text: #f0f0f0 — Secondary: #888 / #555 / #444 / #333
- Borders: `border-[#1f1f1f]` → hover `border-[#333]` or `border-[#f97316]/30`
- Accent: **#f97316** — CTA hover: **#ea580c** — soft glows: `bg-[#f97316]/5`, `border-[#f97316]/20`
- Mono font: font-mono (Geist Mono via CSS var --font-mono)
- Prefer hex arbitrary values for UI chrome; avoid generic Tailwind palette classes unless they match those hex values.
- Cards: rounded-xl — Buttons: rounded-lg
- Page containers: max-w-4xl mx-auto px-4 sm:px-6 (about page: max-w-3xl)
