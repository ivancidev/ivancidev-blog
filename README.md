Personal blog and portfolio built with Astro 6. Articles about React, TypeScript, Node.js, and modern web development. Tools and project showcase with real screenshots.

## Stack

| Layer | Tech |
|-------|------|
| Framework | [Astro 6](https://astro.build) — static output, zero JS by default |
| Content | MDX via `@astrojs/mdx` + Content Collections |
| Styles | Tailwind CSS v3 + `@tailwindcss/typography` |
| Fonts | Geist & Geist Mono (local WOFF) |
| Sitemap | Auto-generated by `@astrojs/sitemap` |
| Package manager | pnpm |
| Deploy | Vercel |

## Getting Started

```bash
pnpm install
pnpm dev
```

> [!TIP]
> Dev server runs at **http://localhost:4321** (not 3000 — that's Next.js).

```bash
pnpm build    # production build → dist/
pnpm preview  # preview the production build locally
```

## Adding a Blog Post

Create a new `.mdx` file in `src/content/blog/`:

```mdx
---
title: "My Post Title"
excerpt: "Short description shown in listings."
date: "2026-04-18"
readTime: "5 min"
tags: ["Astro", "TypeScript"]
featured: true
---

## Introduction

Your content here. Code blocks are syntax-highlighted automatically via Shiki.
```

> [!NOTE]
> The filename becomes the URL slug — `my-post.mdx` → `/blog/my-post`.
> Set `featured: true` to show it on the Home page (max 3 posts shown).

## Adding a Project/Tool

Edit `src/lib/data.ts` and add an entry to the `tools` array:

```ts
{
  id: "my-project",
  name: "My Project",
  description: "What it does.",
  tags: ["React", "TypeScript"],
  github: "https://github.com/ivancidev/my-project",
  url: "https://my-project.vercel.app/",
  status: "live",           // "live" | "wip" | "archived"
  featured: true,           // shows on Home (max 3)
  image: "https://res.cloudinary.com/...",
}
```

> [!TIP]
> Upload screenshots to [Cloudinary](https://cloudinary.com) and paste the URL in `image`.
> Tools without an image show a code icon placeholder instead.

## Design Tokens

| Token | Value |
|-------|-------|
| Accent | `#00ff88` |
| Accent hover | `#00cc6e` |
| Background | `#0a0a0a` |
| Surface | `#111` / `#161616` |
| Border | `#1f1f1f` → `#333` on hover |
| Text primary | `#f0f0f0` |
| Text secondary | `#888` / `#555` |

> [!WARNING]
> Never use standard Tailwind color classes (`blue-500`, `green-400`, etc.).
> Always use the hex values above to keep the design consistent.

## Deploy

The project is configured for **static output** on Vercel. Push to `main` and Vercel picks it up automatically. No adapter needed for static sites.

Update `site` in `astro.config.mjs` if you change the domain:

```js
export default defineConfig({
  site: 'https://your-domain.com',
  // ...
});
```
